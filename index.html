API & CURL

POST muskekk.github.io/asco/api/text

curl -X POST https://muskekk.github.io/asco/api/text \ -H "Content-Type: application/json" \ -d '{"text":"ASCO","depth":12,"rotX":20,"rotY":40}'

POST muskekk.github.io/asco/api/image

curl -X POST https://muskekk.github.io/asco/api/image \ -F "file=@photo.jpg" \ -F "width=120" \ -F "gamma=0.7"
